## About The Project

Antarctica Unveiled is a data visualization project that explores environmental trends in Antarctica through detailed graphs and a dedicated website. The graphs, created using Looker Studio, showcase critical data such as population trends of penguins, ice mass shifts, and changes in the ozone hole area over time. These visualizations are presented on a website designed with HTML and CSS, providing an engaging and accessible platform for understanding key climate insights.

### Built With

* HTML
* CSS
* Looker Studio
